# Simple-Installer

Это пакет для создания простых установщиков. Просто запакуй папку и отредактируй пару файликов и у тебя уже есть нечто, что можно использовать.

# Установка

## Rust 

Скачайте Rust компилятор и cargo. Если вы читаете этот репозиторий, значит вы разработчик, так что сможете разобраться по этому: [Download Rust](https://rust-lang.org/tools/install/)

## Python

Тут нужен Python версии 3.14+, и библиотеки:
```sh
pip install zstandard shutil
```

## Git

Самое простое: Скачайте Git как архив .zip, а после распакуйте. Либо же воспользуйтесь к `git clone`

# Использование

Для начала откройте `src\assets` там содержатся файлы `LICENSE` и `description.toml`. Первый, это файл лицензии, что отображается в установщике, а второй это данные с описанием, что открываются на первой странице. 

После запустите скрипт `create_a_build.py` из директории скаченного архива. 

Во время работы потребуется ввести две вещи: 
1. Название приложения. Это влияет на то, что будет указано в названии окна.
2. Путь к папке приложения. Указанная папка в последствии будет сжата

После того, как скрипт закончит работу в рабочей директории появится готовый `setup.exe`.
